# ktds-MS-AI

1. 프로젝트명
   Azure 기반 VOC 세부 이슈 군집 분석

2. 프로젝트 설명
   VOC 군집 분석을 통하여 빈도수가 많은 이슈 분석 및 개선 Point 검색

3. MVP 핵심 기능 설계

   - 클러스터 및 카운트 집계를 통하여 VOC TOP 이슈군 확인
   - Python/Streamlit 등에서 세부 이슈 추출·의미군집·클러스터별 분석 및 시각화

4. 구축 목표
   VOC 이슈 패턴의 자동 정규화 및 군집화
   GPT API 활용, 각 문의 제목에서 키워드·세부이슈·대표 클러스터 추출
   고객 이슈 흐름의 네트워크형 시각화
   이슈 간 상관성·유사성을 직관적으로 파악하는 3D 네트워크 그래프
   사용자 맞춤형 분석 UX
   실시간 키워드 필터링
   클러스터명 추천/직접입력 및 유연한 오타/유사명 처리(완전일치·부분일치·유사도 매칭)
   클러스터별 이슈 집중 분석 및 전체 이슈 분포 파악

5. 활용기술
6. 활용 기술 및 주요 구조
   영역 활용 기술/라이브러리 역할
   데이터 적재 pandas, Azure Blob Storage 대량 VOC 데이터 수집/로딩
   자연어분석 Azure OpenAI(GPT), 정규식, JSON VOC 문의 제목별 주요 키워드/이슈/군집 추출
   병렬처리 concurrent.futures 빠른 GPT 분석
   네트워크 분석/시각화 networkx, plotly.graph_objects(3D) 클러스터-이슈 네트워크 그래프
   웹 대시보드 Streamlit 사용자 인터페이스 및 인터랙션
   핵심 흐름 및 기능 요약
