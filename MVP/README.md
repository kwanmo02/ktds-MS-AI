# ktds-MS-AI

## 1. 프로젝트명

**Azure 기반 VOC 세부 이슈 군집 분석**

---

## 2. 프로젝트 설명

VOC 군집 분석을 통하여 빈도수가 많은 이슈 분석 및 개선 Point 검색

---

## 3. MVP 핵심 기능 설계

- 클러스터 및 카운트 집계를 통하여 VOC TOP 이슈군 확인
- Python/Streamlit 등에서 세부 이슈 추출·의미군집·클러스터별 분석 및 시각화

---

## 4. 구축 목표

- VOC 이슈 패턴의 자동 정규화 및 군집화
- GPT API 활용, 각 문의 제목에서 키워드·세부이슈·대표 클러스터 추출
- 고객 이슈 흐름의 네트워크형 시각화  
  (이슈 간 상관성·유사성을 직관적으로 파악하는 3D 네트워크 그래프)
- 사용자 맞춤형 분석 UX
  - 실시간 키워드 필터링
  - 클러스터명 추천/직접입력 및 유연한 오타/유사명 처리(완전일치·부분일치·유사도 매칭)
  - 클러스터별 이슈 집중 분석 및 전체 이슈 분포 파악

---

## 5. 예시 데이터 구조

| VOC 제목                                       | 주요 키워드          | 세부 이슈       | 의미적 군집(예시)      |
| ---------------------------------------------- | -------------------- | --------------- | ---------------------- |
| 1. 유심변경후 데이터속도 제한 문의             | 유심변경, 데이터속도 | 데이터속도 제한 | **A (속도 이슈)**      |
| 2. USIM 이동성 시도시 기타에러로 실패되어 문의 | USIM 이동성, 에러    | 기타에러, 실패  | **B (에러/실패 이슈)** |
| 3. 해지 단말 유심이동 불가 문의                | 유심이동, 해지단말   | 불가            | **C (불가 이슈)**      |
| 4. 유심이동 불가 문의                          | 유심이동             | 불가            | **C (불가 이슈)**      |

---

## 6. 주요 활용 기술

- **Python, Pandas, NetworkX, Plotly**: 데이터 가공 및 네트워크 시각화
- **Streamlit**: 대시보드·사용자 인터페이스
- **Azure OpenAI GPT, Azure Blob Storage**: 세부 이슈/군집 자동 추출, 대용량 VOC 데이터 관리
- **정규표현식, difflib**: 키워드/클러스터 입력값 유연 매칭(오타, 유사어 지원)

---

## 7. 고도화 방안

1.  AG가 내부(또는 외부) 지식베이스(예: 과거 유사 VOC, 조치이력, 기술문서, FAQ 등)에서 해당 이슈와 유사하거나 근거가 되는 문서들을 임베딩 벡터 기반으로 검색
2.  RAG를 통해 과거 동일/유사 케이스, 자주 실수되는 패턴, 이전 대응 성공/실패 사례, 공식 가이드라인 등을 실시간 검색
3.  RAG 체인이 그와 연관된 근거/유사사례/원문/트렌드/최근 이슈를 수집, LLM이 자동으로 리포트 초안 생성
4.  현장의 문제 VOC와 연관된 숨어있던 신규 이슈나 패턴까지 적극적으로 노출시켜 위기관리 지원
